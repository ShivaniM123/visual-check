Google PageSpeed Insights

The Lighthouse comparison uses the free PageSpeed Insights API. It works without a key, but the shared quota often runs out. A free key from Google Cloud (enable "PageSpeed Insights API") gives you 25,000 tests a day. The key is stored in this browser's extension storage only.
